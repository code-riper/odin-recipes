# Odin Recipes

This project is a basic HTML website that contains different recipes.
It includes pages for dishes like Chicken Chowmein, Hasselback Potatoes, and Roasted Fish.

## Skills Demonstrated

* Writing basic HTML structure (boilerplate)
* Using headings, paragraphs, lists (`ul`, `ol`)
* Adding links using `<a>` tag
* Organizing files and folders properly
* Creating multiple pages and linking them together

## Purpose

The purpose of this project is to practice and understand the fundamentals of HTML and how to build a simple website.
